Guida al caricamento su GitHub Pages

Pubblica gratis la tua applicazione sul tuo account GitHub in meno di 2 minuti.

1 Crea la repository su GitHub

Accedi a GitHub.com e crea una nuova repository pubblica (es. vaultify-media).

2 Struttura dei File consigliata

Puoi usare un singolo file index.html oppure separare il codice:

📁 vaultify-media/

├── 📄 index.html (Codice principale dell'app)

├── 📄 styles.css (Stili personalizzati o Tailwind)

├── 📄 app.js (Logica JS, Scanner e chiamate API)

└── 📄 README.md (Documentazione del tuo progetto)

3 Attiva GitHub Pages

  1. Entra nella pagina della tua repository su GitHub.
  2. Vai nella scheda Settings → Pages (nel menu a sinistra).
  3. In Build and deployment, imposta il ramo (Branch) su main e seleziona la cartella /(root).
  4. Fai clic su Save. In circa 60 secondi il tuo sito sarà live all'indirizzo: https://tuo-utente.github.io/vaultify-media/
